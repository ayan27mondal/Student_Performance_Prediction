# Student_Performance_Prediction
Machine Learning classification project for predicting student academic performance based on factors such as study hours, attendance, sleep patterns, social media usage, and previous academic records. The project includes data preprocessing, exploratory data analysis, feature engineering, model training, and classification performance evaluation.

# 📌 Project Overview

This project focuses on analyzing and predicting student academic performance using Machine Learning classification algorithms.  
The system predicts student performance categories based on various academic, behavioral, and lifestyle factors such as study hours, attendance, sleep patterns, previous scores, and social media usage.

The project includes complete data preprocessing, exploratory data analysis (EDA), feature engineering, model training, and performance evaluation.

# 🤖 Machine Learning Models Used

The following classification algorithms were trained and evaluated:

## 1️⃣ Logistic Regression
Used as a baseline classification model for predicting student performance categories.

## 2️⃣ Decision Tree Classifier
Captured complex decision boundaries and non-linear relationships between student attributes.

## 3️⃣ Random Forest Classifier
An ensemble learning algorithm that improved prediction accuracy and reduced overfitting.
